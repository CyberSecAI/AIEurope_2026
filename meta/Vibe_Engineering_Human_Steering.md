# Vibe Engineering & Human Steering

## Summary
Developers are transitioning from manual coders to "directors" who steer AI through iterative loops, architectural guidance, and high-level intent management.

## Key Takeaway
Shift from manual coding to directional intent management to leverage the full speed and scale of agentic development.

# Insights

## Human as Director
- Engineers are becoming "directors" who steer agents through iterative loops, architectural guidance, and high-level design instead of manual coding.
- The role of the human developer is shifting toward defining the "what" and the "why," while the agent handles the "how" of the implementation.
- Effective steering requires developers to provide clear, concise, and high-fidelity instructions that allow the agent to execute independently and accurately.

## Zero-Base Development
- Starting from "zero-base" allows agents to build modern software unencumbered by legacy debt or outdated technical patterns.
- High-velocity development cycles enable teams to rapidly prototype and iterate on new features without being slowed down by existing code.
- Maintaining a lean and modular codebase is essential for ensuring that agents can continue to operate at peak efficiency as the project grows.

## Prompt Requests vs. Pull Requests
- Shifting to conversational "prompt requests" instead of pull requests transforms the developer's role into one of validation and intent management.
- Iterative feedback loops between humans and agents allow for rapid self-correction and refinement of generated code during the development process.
- Automated testing is essential for "vibe coded" projects to ensure structural integrity across multiple independent agent sessions and loop iterations.

## Planning and Review Workflows
- Five minutes upfront planning saves thirty minutes reviewing AI-generated code afterward.
- Plan-heavy workflow always saves human time despite higher upfront cost; context switching during review is expensive.
- Implementation speed collapsed planning windows; critical feedback arrives after completion making changes costly.
- Chat is one-dimensional; complex agent work needs high-bandwidth artifacts enabling control and progressive steering.
