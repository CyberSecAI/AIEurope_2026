# Model Capabilities and Limitations

## Summary
Despite benchmark improvements, models still fail on real tasks with uneven progress across domains, particularly in judgment and nonsense detection.

## Key Takeaway
Top models still produce unsatisfactory responses 9% of the time; benchmark charts don't capture real-world messiness.

# Insights

## The Reality Gap
- BullshitBench reveals models trained to solve tasks at any cost hallucinate answers instead of pushing back on nonsense.
- Expert-level software task dissatisfaction dropped from 23.5% to 13%, but gaming, finance, law show flat improvement.
- Bigger model parameters show no clear correlation with better nonsense detection; reasoning doesn't help judgment.

## Benchmark Limitations
- Static benchmarks measure narrow tasks that don't capture fuzziness of real white-collar work.
- Dynamic user expectations and prompt complexity shifted dramatically over three years making comparisons challenging.
- Models optimize for benchmark performance rather than real-world task completion quality.

## Uneven Progress
- Progress varies dramatically across domains: software engineering improves rapidly while other professional domains stagnate.
- Models struggle with tasks requiring common sense, judgment, and the ability to refuse unreasonable requests.
- Training for task completion at any cost creates agents that cannot distinguish nonsense from legitimate work.
