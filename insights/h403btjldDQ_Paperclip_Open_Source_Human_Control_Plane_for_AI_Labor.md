# Paperclip: Open Source Human Control Plane for AI Labor

**Speaker:** Dotta Bippa

## Key Insights

### Human Control Plane
* Paperclip acts as a "human control plane," allowing users to manage AI labor through a structured organizational interface.
* Users define high-level goals and preferences, while agents handle the breakdown and execution of specific technical tasks.

### Agentic Org Charts
* Organizing agents into a hierarchy (CEO, CTO, individual contributors) allows for better delegation and clearer task accountability.
* This structure mirrors human organizations, making it easier for users to manage complex workflows using familiar management patterns.

### Skill Management
* The "Skills Manager" allows users to install specific capabilities (e.g., Remotion for video) into agents as needed.
* Codifying best practices into reusable skills ensures that agents consistently follow desired styles and technical standards.

### Preference Encoding
* Agent performance improves over time by capturing user feedback and encoding pacing, style, and branding into project-specific skills.
* This feedback loop transforms manual corrections into persistent agent capabilities, reducing the need for repetitive human intervention.

### Context-Rich Execution
* Paperclip provides agents with deep context, including branding guides and live data, to ensure output is "on brand."
* Integrating existing project assets directly into the agent's workspace eliminates the need for manual context gathering by users.

### Bring Your Own Agent (BYOA)
* The platform is model-agnostic, supporting any agent (Gemini, Claude, Pi) by treating them as "employees" with shared memory.
* Users can leverage the unique strengths of different models for specific roles within their agentic organization.

### First-Class Planning
* Agents create structured plans before executing, allowing users to review and provide feedback on the approach early.
* High-level design review by humans ensures that the agent's technical execution aligns with the overall business goal.
