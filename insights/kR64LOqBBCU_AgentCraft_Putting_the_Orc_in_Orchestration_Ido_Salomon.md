# Overview

## Summary
Ido Salomon presents AgentCraft, an orchestration platform applying gaming UX patterns to multi-agent coding workflows.

## Key Takeaway
Gaming interfaces solve agent orchestration by visualizing activity and enabling muscle-memory-based reactions.

# Insights

## The Orchestration Bottleneck
- Humans are the bottleneck in multi-agent systems, not the agents themselves or infrastructure.
- Managing dozens of agents requires skills we already have from gaming, not entirely new capabilities.
- Engineers aren't built for babysitting reckless employees; orchestration needs systematic interface design.

## Visibility Through Spatial Mapping
- File systems projected as spatial maps let you see which agent works on which file instantly.
- Heat maps of agent activity reveal and prevent collisions before they cause merge conflicts.
- Visual lineage tracking shows which agent made what change and when, eliminating attribution mystery.

## Muscle Memory Orchestration
- RTS game mechanics enable rapid cycling between agents needing approval using keyboard shortcuts.
- React to agent states through practiced patterns rather than scanning endless notification lists.
- Quick transitions between idle, working, and blocked agents reduces context-switching cognitive load.

## Agent-Generated Work Discovery
- Agents can discover and propose their own tasks, not just execute human-defined missions.
- Quest systems offload idea generation to agents for refactoring, testing, and maintenance work.
- Campaign mode lets agents decompose broad goals autonomously and present completed plans for review.

## Isolation for Autonomy
- Running agents in containers removes babysitting overhead by containing their experimental workspace safely.
- Campaign orchestrators manage sub-agents, shifting human effort from execution monitoring to planning and review.
- Multiple parallel implementation attempts enable picking best results rather than perfecting single plans upfront.

## Human-Agent Collaboration Modes
- Shared workspaces enable designer-developer handoffs where each sees the other's agents working live.
- Soft collaboration through chat lets agents know when humans are working on overlapping files.
- Visual evidence bundles with screenshots and videos enable fast PR review without deep code inspection.

## Team Multiplayer Orchestration
- Workspaces shared between team members make agent activity transparent across roles.
- Product designers can spawn agents that engineers continue from, creating continuous design-to-code pipelines.
- Agents participate in team chat alongside humans, announcing work and detecting potential conflicts.

## Shift to Review-Heavy Workflows
- Running tasks 10 times and selecting the best shifts effort from careful planning to informed selection.
- Autonomous channels scanning Twitter for ideas demonstrate fully self-directed agent workflows.
- Human role moves toward approving plans and reviewing bundles rather than directing every action.
