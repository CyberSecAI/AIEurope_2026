# Overview

## Summary
Malte Ubl, CTO of Vercel, discusses how AI agents represent a new application layer and the future of software engineering.

## Key Takeaway
Software engineers remain essential as AI agents expand what's economically viable to build, increasing overall demand.

# Insights

## Economic Transformation of Software Development
- Agents make previously uneconomical automation viable, expanding the total addressable software market beyond traditional economic constraints.
- Companies increasingly answer "make vs buy" with "make" using agents, accelerating the SaaS copocalypse trend in Silicon Valley.
- Demand for software engineers rises as cheaper production costs unlock exponentially more software creation opportunities through elastic market dynamics.

## Low-Hanging Fruit Agent Patterns
- Agent-as-a-Service replaces human 9-to-5 jobs with 24/7 availability, transforming support and operational roles without massive process changes.
- Compressed research agents automate the research phase between business events and decisions, reducing 30-minute tasks to five minutes.
- Eliminating boring work dramatically increases employee satisfaction; Vercel's support team job satisfaction exploded after 90% deflection rate automation.

## Information Surfacing Opportunities
- Most valuable immediate impact surfaces existing company information that's technically available but practically inaccessible to decision-makers.
- Issue trackers stay outdated because information exists scattered across Slack, meeting recordings, yet agents can consolidate it automatically.
- Ask "what do you hate most about your job" to identify high-impact automation candidates that improve both efficiency and morale.

## Infrastructure Paradigm Shifts
- Over 60% of Vercel.com page views now come from AI agents, not humans, fundamentally changing web traffic composition.
- Usage shifted from dashboard clicking to API and CLI interactions as automation becomes the primary interface for platforms.
- When evaluating new features, prioritize "how does an agent use this" over UI, as automation is becoming the dominant interaction model.

## Agent-Written Code Deployment Model
- When agents write most code, developers lose attachment to infrastructure deployment details, requiring new zero-configuration deployment paradigms.
- Infrastructure must support code that was prompted into existence and should "just run" without manual deployment configuration.
- Separation between where agent harness runs and where generated code executes is architecturally critical for security.

## Security and Architecture Evolution
- Most popular agent harnesses have fundamentally wrong architecture by combining harness location with code execution location, creating security vulnerabilities.
- The industry faces a 1999-style security nightmare where everything can be hacked, requiring open-mindedness about paradigm shifts.
- Anthropic's new agent product demonstrates correct separation architecture, validating the need for isolated execution environments.

## Europe's AI Engineering Leadership
- Europe leads AI engineering innovation despite lacking model development leadership through tools like Vercel AI SDK, PIA coding agent, and OpenClaw.
- Vercel AI SDK has 10 million downloads weekly, led by Lars Gammel from Berlin, proving application layer innovation transcends model access.
- AI engineering creates stable value independent of model volatility, allowing engineers to drive innovation without working at model labs.

## Model Commoditization Future
- Google's infrastructure cost advantage will drive continuous price reduction, keeping models cheap and preventing monopolistic model lab dominance.
- Commoditized models shift value creation to the application layer where AI engineers build agents that generate actual business value.
- If model labs win and AI stays expensive, engineers become forward-deployed consultants; if models commoditize, engineers remain powerful innovators.
