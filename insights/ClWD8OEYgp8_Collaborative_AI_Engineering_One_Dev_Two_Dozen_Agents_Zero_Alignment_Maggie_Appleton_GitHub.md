# Overview

## Summary
Maggie Appleton from GitHub Next presents ACE, a collaborative environment rethinking software development for the agentic era.

## Key Takeaway
Team alignment before implementation beats individual speed; build fewer things better, not faster chaos.

# Insights

## The Alignment Crisis

- Implementation speed collapsed planning windows; critical feedback now arrives after code completion, making changes costly.
- Coding agents create unshared local plans invisible to teams, multiplying coordination debt through parallel conflicting work.
- Pull requests inherit all alignment burden after implementation when course correction is expensive, not their original purpose.

## Opportunity Cost Over Production Cost

- When code generation becomes cheap, choosing what NOT to build becomes the real competitive advantage.
- Individual productivity improvements create nine-women-make-a-baby-in-one-month logic; more output worsens communication problems rather than solving them.
- Fast cheap software shifts quality from nice-to-have to primary differentiator; craftsmanship separates products from vibe-coded slop.

## Context Lives Outside Code

- Business constraints, political dynamics, product vision, and organizational history determine correct solutions but exist only in people's heads.
- Agents cannot discover critical decision-making context independently; humans must share it early and naturally without process overhead.
- Social information fabric around code enables agents to proactively surface relevant context, notify about decisions, pull experts in.

## Collaborative Development Infrastructure

- Each session combines multiplayer chat with isolated micro-VM on dedicated Git branch, enabling instant parallel work switching.
- Shared cloud computers eliminate works-on-my-machine syndrome; all team members access identical previews, terminals, prompting history immediately.
- Real-time multiplayer editing in VS Code plus persistent sessions means closing laptop doesn't kill work; teammates continue progress.

## Planning as Continuous Cycle

- Planning and building are no longer sequential phases but interwoven cycles requiring constant team alignment during implementation.
- Collaborative plan editing with visible cursors lets teams validate agent proposals before execution, catching misalignment before wasted work.
- Accessible Slack-like interfaces democratize agent access beyond developers to designers, PMs, customer support creating shared context.

## Reclaiming Time for Craft

- Implementation time reduction creates opportunity to invest in user research, design details, architecture implications previously sacrificed under deadlines.
- Agents scaling teams correctly leads to better quality software through rigorous critical thinking, not just faster feature volume.
- Team dashboards with AI-generated summaries solve visibility crisis where coworkers now ship five features daily instead of half.

## Tool Evolution Requirements

- Existing coordination tools GitHub, Slack, Jira, Linear designed for pre-agentic workflows; funneling agent outputs into them creates friction.
- Future tools must unify planning, context gathering, decision-making, and development under one roof rather than fragmented platforms.
- Backward compatibility through PR generation with ACE session links allows gradual team adoption without forcing full migration.
