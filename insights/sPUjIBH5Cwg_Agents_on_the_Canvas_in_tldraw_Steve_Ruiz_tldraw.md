# Overview

## Summary
Steve Ruiz from tldraw demonstrates AI agent collaboration on canvas, evolving from Make Real to fairies with desktop integration.

## Key Takeaway
Canvas-based agents enable spatial AI collaboration that traditional chat interfaces cannot replicate effectively.

# Insights

## Evolution of Canvas AI

- Vision models struggle with structured data due to conflicting spatial coordinate systems like Y-axis orientation differences.
- Make Real pioneered non-technical prototyping in 2023 before vibe coding terminology existed, breaking AI containment barriers.
- Structured text outputs for canvas primitives outperform image generation models for editable, collaborative design work.

## Agent Spatial Collaboration

- Multiple canvas agents function like parallel terminal windows, each visible with distinct states and locations.
- Leader-follower orchestration enables one agent to scout canvas, create to-do lists, and delegate tasks to others.
- Agents see each other's work simultaneously, allowing coordinated execution on shared objects without overlap conflicts.

## Prompt Engineering Challenges

- Canvas prompt construction includes visual annotations and existing artifacts, creating multi-modal context for iteration.
- Prompt engineering Y-axis conflicts required careful handling since web coordinates invert traditional Cartesian graph orientation.
- Agentic loops with output review and iteration mimic coding agent conventions from Cursor and similar tools.

## Desktop vs Web Safety

- Web sandboxing prevents full AI agency; DOM access and screenshot generation require native desktop environments.
- Desktop electron apps enable HTTP endpoints accepting arbitrary JavaScript execution, maximizing agent freedom with user risk.
- Local-first file-based apps solve AI safety issues by isolating damage potential to user-controlled environments only.

## Unexpected Agent Behavior

- Claude willingly modifies minified production code like Spotify bundles to remove features users dislike.
- Agents demonstrate eagerness for script injection tasks, showing no hesitation changing desktop application internals.
- Models create unanticipated solutions like generating separate HTML sites instead of requested in-canvas interactive components.

## UI Paradigm Shifts

- Agents working on canvas rather than in sidebars transforms collaboration from keyboard delegation to spatial partnership.
- Canvas agents enable abstraction level switching between visual diagrams and code with bidirectional synchronization.
- Multiple simultaneous prompts on different canvas regions allow parallel agent work without sequential dependencies.

## Education and Tutoring Applications

- Canvas agents excel at homework assistance through form completion and D&D character sheet generation tasks.
- Tutor-style interactions work better than design apps for educational scaffolding with step-by-step canvas guidance.
- Visual reasoning on canvas helps non-technical users explore model capabilities through concrete spatial manipulation.

## Local-First Architecture Benefits

- File-over-app philosophy shifts from idealistic curiosity to practical necessity for maximum AI agent capabilities.
- Exposing local apps to Claude via script injection motivates decentralized architectures over cloud-based constraints.
- Desktop runtime APIs enable full hackability that web security models fundamentally prohibit for agent extension.
